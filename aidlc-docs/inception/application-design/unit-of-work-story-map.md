# 테이블오더 서비스 - Unit of Work Story Map

## 스토리-유닛 매핑 개요

모든 44개 스토리가 3개 유닛에 매핑됩니다.
- 각 스토리의 **백엔드 API** 부분은 Unit 1에 포함
- 각 스토리의 **프론트엔드 UI** 부분은 해당 유닛(Unit 2 또는 Unit 3)에 포함
