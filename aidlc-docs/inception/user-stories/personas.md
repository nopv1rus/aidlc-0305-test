# 테이블오더 서비스 - 페르소나

## Persona 1: 고객 (Customer)

| 항목 | 내용 |
|------|------|
| 이름 | Jake (대표 페르소나, 진상 고객 성향이 있음.) |
| 역할 | 식당 방문 고객 |
| 접속 방식 | 테이블 QR코드 스캔 → 모바일 브라우저 |
| 기술 수준 | 다양 (스마트폰 기본 사용 가능) |
| 목표 | 빠르고 편리하게 음식 주문, 대기 시간 최소화 |
| 불만 사항 | 직원 호출 대기, 복잡한 주문 과정, 주문 상태 불확실 |
| 사용 빈도 | 매장 방문 시마다 (비정기적) |
| 디바이스 | 개인 스마트폰 (다양한 화면 크기) |
| 핵심 니즈 | 직관적 UI, 빠른 로딩, 실시간 주문 상태 확인 |

**사용자 여정**: QR스캔 → 메뉴 탐색 → 장바구니 담기 → 주문 확정 → 주문 상태 확인 → (추가 주문 반복)

## Persona 2: 매장 관리자 (Store Admin)

| 항목 | 내용 |
|------|------|
| 이름 | Terry (대표 페르소나) |
| 역할 | 매장 운영 담당자 (점장/매니저) |
| 접속 방식 | 데스크톱 브라우저 로그인 |
| 기술 수준 | 중간 (기본 컴퓨터 사용 가능) |
| 목표 | 효율적인 주문 관리, 매장 운영 최적화 |
| 불만 사항 | 주문 누락, 테이블 상태 파악 어려움, 수작업 관리 |
| 사용 빈도 | 매일 영업 시간 동안 상시 |
| 디바이스 | 데스크톱/노트북 (카운터 설치) |
| 핵심 니즈 | 실시간 주문 모니터링, 빠른 상태 변경, 테이블 관리 |

**사용자 여정**: 로그인 → 대시보드 모니터링 → 주문 상태 변경 → 테이블 세션 관리 → 메뉴 관리 → 과거 내역 조회

## Persona 3: 슈퍼 관리자 (Super Admin)

| 항목 | 내용 |
|------|------|
| 이름 | Jasper (대표 페르소나) |
| 역할 | 시스템 전체 관리자 (본사/운영팀) |
| 접속 방식 | 데스크톱 브라우저 로그인 |
| 기술 수준 | 높음 (시스템 관리 경험) |
| 목표 | 다수 매장의 통합 관리, 매장 관리자 계정 관리 |
| 불만 사항 | 매장별 개별 관리의 비효율, 계정 관리 복잡성 |
| 사용 빈도 | 필요 시 (매장 추가, 계정 관리 등) |
| 디바이스 | 데스크톱/노트북 |
| 핵심 니즈 | 매장/계정 일괄 관리, 권한 제어 |

**사용자 여정**: 로그인 → 매장 관리 → 매장 관리자 계정 생성/관리 → 시스템 설정
