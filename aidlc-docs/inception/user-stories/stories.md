# Journey 1: 고객 주문 여정 (Customer)

## Epic: QR코드 접속 및 세션 관리

### US-C01: QR코드 스캔으로 주문 페이지 접속
**As a** 고객, **I want to** 테이블의 QR코드를 스캔하여 주문 페이지에 접속하고 싶다, **so that** 별도 앱 설치나 로그인 없이 바로 주문할 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- Given 고객이 테이블에 부착된 QR코드를 스캔했을 때
- When 모바일 브라우저가 열리면
- Then 해당 매장의 해당 테이블 메뉴 화면이 즉시 표시된다
- And 별도 로그인/비밀번호 입력이 요구되지 않는다
- And URL에는 추측 불가능한 테이블 토큰이 포함된다

### US-C02: 고객 세션 유지
**As a** 고객, **I want to** 접속 후 최대 4시간 동안 세션이 유지되길 원한다, **so that** 식사 중 반복적으로 QR코드를 스캔하지 않아도 된다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] 세션 유효 시간은 최대 4시간
- [ ] 4시간 경과 시 세션 만료, QR코드 재스캔 필요
- [ ] 브라우저 탭을 닫았다 다시 열어도 4시간 이내면 세션 유지
- [ ] 관리자가 이용 완료 처리 시 세션 즉시 종료

### US-C03: 동시 접속 시 테이블 세션 공유
**As a** 고객, **I want to** 같은 테이블의 다른 사람들과 동시에 QR코드를 스캔해도 같은 테이블 세션을 공유하고 싶다, **so that** 일행 모두가 각자 주문할 수 있다.
**Priority**: P1
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- Given 같은 테이블의 QR코드를 여러 고객이 스캔했을 때
- When 각 고객이 주문 페이지에 접속하면
- Then 모두 같은 테이블 세션을 공유한다
- And 각 고객의 장바구니는 독립적으로 관리된다
- And 누구나 주문을 생성할 수 있다

## Epic: 메뉴 조회 및 탐색

### US-C04: 카테고리별 메뉴 목록 조회
**As a** 고객, **I want to** 카테고리별로 분류된 메뉴 목록을 보고 싶다, **so that** 원하는 종류의 음식을 빠르게 찾을 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] 메뉴 화면이 기본(홈) 화면으로 표시
- [ ] 카테고리 탭/버튼으로 메뉴 분류 표시
- [ ] 카테고리 선택 시 해당 카테고리 메뉴만 필터링
- [ ] 카드 형태 레이아웃으로 메뉴 표시

### US-C05: 메뉴 상세 정보 확인
**As a** 고객, **I want to** 메뉴의 상세 정보(이름, 가격, 설명, 이미지)를 확인하고 싶다, **so that** 주문 전에 메뉴에 대해 충분히 알 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] 메뉴 카드에 메뉴명, 가격, 이미지 표시
- [ ] 메뉴 카드 클릭 시 상세 정보(설명 포함) 표시
- [ ] 이미지가 없는 메뉴는 기본 플레이스홀더 이미지 표시
- [ ] 터치 친화적 버튼 크기 (최소 44x44px)

### US-C06: 카테고리 간 빠른 이동
**As a** 고객, **I want to** 카테고리 간에 빠르게 이동하고 싶다, **so that** 여러 종류의 메뉴를 효율적으로 탐색할 수 있다.
**Priority**: P1
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] 카테고리 탭이 화면 상단에 고정 표시 (카테고리가 많을 경우 가로 스크롤 가능한 탭 바)
- [ ] 카테고리 탭 클릭 시 해당 섹션으로 스크롤 이동
- [ ] 현재 보고 있는 카테고리가 시각적으로 강조

## Epic: 장바구니 관리

### US-C07: 메뉴를 장바구니에 추가
**As a** 고객, **I want to** 원하는 메뉴를 장바구니에 추가하고 싶다, **so that** 여러 메뉴를 모아서 한 번에 주문할 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- Given 고객이 메뉴 화면에서 메뉴를 선택했을 때
- When "장바구니 추가" 버튼을 누르면
- Then 해당 메뉴가 장바구니에 추가된다
- And 이미 장바구니에 있는 메뉴면 수량이 1 증가한다
- And 장바구니 아이콘에 총 수량이 표시된다

### US-C08: 장바구니 메뉴 수량 조절
**As a** 고객, **I want to** 장바구니에 담긴 메뉴의 수량을 증가/감소시키고 싶다, **so that** 원하는 만큼 주문할 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] +/- 버튼으로 수량 조절 가능
- [ ] 수량이 0이 되면 장바구니에서 자동 삭제
- [ ] 수량 변경 시 총 금액 즉시 재계산
- [ ] 최소 수량: 1

### US-C09: 장바구니에서 메뉴 삭제
**As a** 고객, **I want to** 장바구니에서 특정 메뉴를 삭제하고 싶다, **so that** 잘못 담은 메뉴를 제거할 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] 각 메뉴 항목에 삭제 버튼 표시
- [ ] 삭제 시 해당 메뉴 즉시 제거
- [ ] 총 금액 즉시 재계산

### US-C10: 장바구니 총 금액 실시간 확인
**As a** 고객, **I want to** 장바구니의 총 금액을 실시간으로 확인하고 싶다, **so that** 주문 전에 총 비용을 알 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] 장바구니 화면에 총 금액 항상 표시
- [ ] 메뉴 추가/삭제/수량 변경 시 즉시 재계산
- [ ] 각 메뉴별 소계(단가 x 수량) 표시

### US-C11: 장바구니 비우기
**As a** 고객, **I want to** 장바구니를 한 번에 비우고 싶다, **so that** 처음부터 다시 메뉴를 선택할 수 있다.
**Priority**: P1
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] "장바구니 비우기" 버튼 제공
- [ ] 클릭 시 확인 팝업 표시
- [ ] 확인 시 모든 메뉴 삭제, 총 금액 0으로 리셋

### US-C12: 장바구니 데이터 로컬 유지
**As a** 고객, **I want to** 페이지를 새로고침해도 장바구니 내용이 유지되길 원한다, **so that** 실수로 새로고침해도 담아둔 메뉴가 사라지지 않는다.
**Priority**: P1
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] 장바구니 데이터를 localStorage에 저장
- [ ] 페이지 새로고침 시 장바구니 복원
- [ ] 세션 만료 또는 이용 완료 시 장바구니 데이터 삭제

## Epic: 주문 생성

### US-C13: 주문 내역 최종 확인
**As a** 고객, **I want to** 주문 확정 전에 주문 내역을 최종 확인하고 싶다, **so that** 잘못된 주문을 방지할 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] 주문 확정 화면에 전체 메뉴 목록, 수량, 단가, 총 금액 표시
- [ ] "주문하기" 버튼과 "돌아가기" 버튼 제공
- [ ] 주문 확정 전 수량 수정 가능

### US-C14: 주문 확정 및 전송
**As a** 고객, **I want to** 장바구니의 메뉴를 주문으로 확정하고 싶다, **so that** 매장에서 음식을 준비해 줄 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- Given 고객이 장바구니에 메뉴가 있는 상태에서
- When "주문하기" 버튼을 누르면
- Then 주문이 서버로 전송된다
- And 주문 정보에 매장 ID, 테이블 ID, 메뉴 목록, 총 금액, 세션 ID가 포함된다

### US-C15: 주문 성공 후 피드백
**As a** 고객, **I want to** 주문 성공 시 주문 번호를 확인하고 싶다, **so that** 주문이 정상 접수되었음을 알 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- Given 주문이 성공적으로 전송되었을 때
- When 서버에서 성공 응답을 받으면
- Then 주문 번호가 화면에 표시된다
- And 장바구니가 자동으로 비워진다
- And 5초 후 메뉴 화면으로 자동 리다이렉트된다

### US-C16: 주문 실패 시 에러 처리
**As a** 고객, **I want to** 주문 실패 시 에러 메시지를 보고 싶다, **so that** 문제를 인지하고 재시도할 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- Given 주문 전송이 실패했을 때
- When 서버에서 에러 응답을 받으면
- Then 사용자 친화적 에러 메시지가 표시된다
- And 장바구니 내용이 유지된다
- And 재주문 시도가 가능하다

## Epic: 주문 내역 조회

### US-C17: 현재 세션 주문 목록 조회
**As a** 고객, **I want to** 현재 테이블 세션의 주문 내역을 확인하고 싶다, **so that** 지금까지 주문한 내용을 파악할 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] 현재 테이블 세션의 주문만 표시 (이전 세션 제외)
- [ ] 주문 시간 순 정렬
- [ ] 매장 이용 완료 처리된 주문 제외

### US-C18: 주문별 상세 정보 확인
**As a** 고객, **I want to** 각 주문의 상세 정보를 확인하고 싶다, **so that** 주문 번호, 메뉴, 금액을 정확히 알 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- [ ] 주문 번호, 주문 시각 표시
- [ ] 주문 메뉴 및 수량 표시
- [ ] 주문 금액 표시
- [ ] 주문 상태 표시 (대기중/준비중/완료)

### US-C19: 주문 상태 실시간 업데이트 수신
**As a** 고객, **I want to** 주문 상태가 변경되면 실시간으로 알고 싶다, **so that** 음식 준비 상황을 바로 확인할 수 있다.
**Priority**: P0
**Persona**: 고객 (김민수)

**Acceptance Criteria**:
- Given 관리자가 주문 상태를 변경했을 때
- When SSE를 통해 상태 변경 이벤트가 전달되면
- Then 고객 화면의 주문 상태가 즉시 업데이트된다
- And 페이지 새로고침 없이 반영된다

# Journey 2: 매장 관리자 운영 여정 (Store Admin)

## Epic: 매장 인증

### US-A01: 관리자 로그인
**As a** 매장 관리자, **I want to** 매장 식별자와 계정 정보로 로그인하고 싶다, **so that** 내 매장의 관리 시스템에 접근할 수 있다.
**Priority**: P0
**Persona**: 매장 관리자 (박서연)

**Acceptance Criteria**:
- Given 관리자가 로그인 페이지에서
- When 매장 식별자, 비밀번호를 입력하고 로그인 버튼을 누르면
- Then JWT 토큰이 발급되고 대시보드로 이동한다
- And 토큰이 브라우저에 안전하게 저장된다

### US-A02: 관리자 세션 유지
**As a** 매장 관리자, **I want to** 16시간 동안 세션이 유지되길 원한다, **so that** 영업 시간 동안 반복 로그인하지 않아도 된다.
**Priority**: P0
**Persona**: 매장 관리자 (박서연)

**Acceptance Criteria**:
- [ ] 세션 유효 시간: 16시간
- [ ] 브라우저 새로고침 시 세션 유지
- [ ] 16시간 경과 시 자동 로그아웃 및 로그인 페이지 리다이렉트

### US-A03: 로그인 시도 제한
**As a** 매장 관리자, **I want to** 비정상적인 로그인 시도가 차단되길 원한다, **so that** 계정 보안이 보장된다.
**Priority**: P1
**Persona**: 매장 관리자 (박서연)

**Acceptance Criteria**:
- [ ] 연속 5회 로그인 실패 시 계정 일시 잠금
- [ ] 잠금 시 사용자에게 안내 메시지 표시
- [ ] 일정 시간 후 자동 잠금 해제

---

## Epic: 실시간 주문 모니터링

### US-A04: 테이블별 주문 대시보드 조회
**As a** 매장 관리자, **I want to** 테이블별 카드 형태의 대시보드를 보고 싶다, **so that** 전체 매장 주문 현황을 한눈에 파악할 수 있다.
**Priority**: P0
**Persona**: 매장 관리자 (박서연)

**Acceptance Criteria**:
- [ ] 그리드 레이아웃으로 테이블별 카드 표시
- [ ] 각 카드에 테이블 번호, 총 주문액 표시
- [ ] 각 카드에 최신 주문 미리보기 표시

### US-A05: 신규 주문 실시간 수신
**As a** 매장 관리자, **I want to** 새 주문이 들어오면 실시간으로 대시보드에 반영되길 원한다, **so that** 주문을 놓치지 않을 수 있다.
**Priority**: P0
**Persona**: 매장 관리자 (박서연)

**Acceptance Criteria**:
- Given 고객이 새 주문을 생성했을 때
- When SSE를 통해 주문 이벤트가 전달되면
- Then 2초 이내에 대시보드에 주문이 표시된다
- And 신규 주문 카드가 시각적으로 강조된다 (색상 변경, 애니메이션)

### US-A06: 주문 상세 정보 확인
**As a** 매장 관리자, **I want to** 테이블 카드를 클릭하여 전체 주문 목록을 보고 싶다, **so that** 해당 테이블의 모든 주문을 상세히 확인할 수 있다.
**Priority**: P0
**Persona**: 매장 관리자 (박서연)

**Acceptance Criteria**:
- [ ] 테이블 카드 클릭 시 상세 주문 목록 표시
- [ ] 각 주문: 주문 번호, 시각, 메뉴/수량, 금액, 상태
- [ ] 닫기 버튼으로 대시보드 복귀

### US-A07: 주문 상태 변경
**As a** 매장 관리자, **I want to** 주문 상태를 변경하고 싶다 (대기중→준비중→완료), **so that** 주문 처리 진행 상황을 관리할 수 있다.
**Priority**: P0
**Persona**: 매장 관리자 (박서연)

**Acceptance Criteria**:
- Given 관리자가 주문 상세에서 상태 변경 버튼을 클릭했을 때
- When 상태를 선택하면 (대기중/준비중/완료)
- Then 주문 상태가 즉시 변경된다
- And 변경된 상태가 고객 화면에 SSE로 실시간 전달된다
- And 대시보드에 변경된 상태가 반영된다
- And 상태 전이: 대기중→준비중→완료 (순방향), 대기중/준비중→취소됨 (가능, 완료 상태에서는 취소 불가)

### US-A08: 테이블별 필터링
**As a** 매장 관리자, **I want to** 특정 테이블의 주문만 필터링하고 싶다, **so that** 원하는 테이블의 주문에 집중할 수 있다.

- [ ] 필터 적용 시 해당 테이블 카드만 표시
- [ ] 필터 해제 시 전체 테이블 표시

### US-A11: 주문 취소
**As a** 매장 관리자, **I want to** 잘못된 주문을 취소하고 싶다, **so that** 고객 요청이나 오류 주문을 처리할 수 있다.

- And 테이블 총 주문액이 재계산된다
- And 성공/실패 피드백이 표시된다
